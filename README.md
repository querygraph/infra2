# AI Infra 2.0 Manifesto

This repository holds the **AI Infra 2.0 Manifesto**, a shared statement from companies and developers building AI infrastructure with Python on top and fast native code (usually Rust) underneath, connected by Apache Arrow.

Read it here: **[manifesto.md](manifesto.md)**

## How to sign

There are two ways to sign:

- **Send a pull request.** Add a line to the *Signed by Companies and Developers* list at the end of [manifesto.md](manifesto.md). Signatures are listed in the order they arrive, so add yours at the bottom. Use this format:

  ```markdown
  - **Your Company or Name**: what you build, in one line.
  ```

- **Open an issue.** Give your company or name and a one-line description of what you build, and we'll add you.
